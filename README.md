# Jogo Caça-Palavras

O Jogo Caça-Palavras é uma aplicação interativa em que o jogador deve encontrar as palavras escondidas no tabuleiro.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
